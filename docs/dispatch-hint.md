# What a request may say, under an empty input (v1.1)

v1.1: while the input is empty, a hint says what a request may carry (the result wanted, the sources to read, what must not be touched, what to deliver, where to stop for the owner); one sentence that leaves things out can still be sent, and the account fills in the rest or asks one question. It is a hint, not a form, and nothing is required.

- **Where** (web `Composer`): one muted line above the input while the conversation is loaded, no reply is under way and the input is empty: 「派活可以说：要什么结果 · 看哪些来源 · 哪些不能碰 · 交付成什么 · 停在哪等你看。一句话写不全也行，缺的号自己补或问你一句。」 (`t.composer.dispatchHint`). It goes as soon as the person types.
- It names no pace, no report timing and no site (the strings' rules, `strings.ts`).
